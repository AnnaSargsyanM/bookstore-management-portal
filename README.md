# Bookstore Management Portal

A relational database application built with **Oracle SQL** and **Oracle APEX** for managing bookstore operations, including books, customers, employees, orders, order items, inventory, and application settings.

The project combines relational database design with an interactive web-based interface for viewing, creating, and updating bookstore data.

## Features

- Manage bookstore inventory and book information
- Store and manage customer records
- Manage employee information
- Create and track customer orders
- Associate books and quantities with individual orders
- View searchable and editable reports
- Add and update records through Oracle APEX forms
- Monitor order activity through a dashboard chart
- Configure application settings such as stock thresholds and currency

## Database Design

The application uses a relational database structure with tables for:

- Books
- Customers
- Employees
- Orders
- Order Items
- Settings

Primary and foreign key relationships connect the tables and maintain relationships between customers, employees, orders, and books.
